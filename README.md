# Betting Mini App

Mobile-friendly betting front-end starter with:

## Games
- Aviator
- Fast Keno
- 777 Chicken Coin
- Chicken Road 2
- JetX
- Chicken Shoot
- Joker Pyre
- Safari Simba
- Bao Slot 5X
- Hot Samba
- Foxy Hot 20
- Football 1X2

The game cards are front-end placeholders and require connection to an authorized/licensed game provider and backend before real-money operation.

For a real-money launch, implement authentication, KYC/age verification, wallet/payment controls, odds validation, secure bet settlement, audit logs and responsible-gambling controls as required by applicable law.
